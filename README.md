# AETHERFALL — 神域の残響

ローポリの王国を、人間サイズの神／悪魔で飛ぶ破壊サンドボックスの操作試作です。初代ヴァルキリープロファイルの俯瞰ワールドマップから「空を飛び、地上の営みを見下ろす」感覚に着想を得ています。地形・建物・キャラクター・UIは今回のために手続き生成した独自のものです。

## 現在の版：飛行デバッグ α0.2

飛行だけの気持ちよさを確かめるため、照射・反撃・攻撃関連HUDは一時停止しています。以下の操作に絞っています。

- **右の前進ボタン**：押している間に前進し、離すと滑らかに減速・停止。
- **左のバーチャルパッド上下**：前進と独立した垂直上昇・下降。その場でも使える。
- **左パッド左右**：左旋回・右旋回。横への平行移動ではない。
- **斜め入力**：上昇と左旋回などを1本の指で同時に操作。前進ボタンとの2点同時タッチに対応。
- **キーボード**：Wで前進、↑↓で垂直移動、←→またはA/Dで旋回。Space/Cでも上下移動可能。
- 機首とカメラの上下角は固定し、上昇・下降しても前進方向が上下へ傾かない。
- `/?demo=1` は攻撃のない自動飛行デモ。元の破壊処理は計算モジュールに保持。

`tests/browser.mjs` はパッドの斜め入力、前進とのマルチタッチ、垂直移動の独立性、入力解除、攻撃停止を確認します。以下の破壊サンドボックスの説明は初期版の機能・設計の記録です。

## 起動

Python 3があれば、プロジェクトのフォルダで以下を実行してください。

```bash
python3 -m http.server 4173 --directory dist
```

ブラウザで <http://localhost:4173> を開きます。ゲーム本体のnpmインストールやビルドは不要です。Three.js 0.187.0を同梱しています。WebGL 2対応ブラウザで遊べます。最初の画面の「飛行デモを見る」、または `/?demo=1` で自動飛行を観察できます。

## 今回できること

- 約400m四方の島を後方カメラで自由飛行。通常32m/s、加速時97m/sを目標速度とする慣性移動。
- 人間サイズの翼あるキャラクター。光の神／闇の悪魔をガイド画面で切り替え。
- 神の光の連続照射で、城・民家・外壁の約5,500ボクセルを破壊。木・石・屋根材で耐久力と燃焼特性が異なる。
- 地面の4mブロック列を削り、段状のクレーターを残す。草地が削れると土・岩の断面が現れる。
- 熱の蓄積、着火、近隣への延焼、燃え尽き。石は燃えない。
- 地面に接続しなくなった建物の部分を検出し、崩落させる。
- 56人のドット絵住民が地上を移動し、照射地点・低空のプレイヤーから逃げる。
- 3基の投石機が放物線の岩を、3人の魔導師が追尾弾を撃つ。足場を破壊すると停止。
- 反撃の命中、神威の回復、尽きたときの天空への復帰。ミニマップ、一時停止、世界再生成、サウンドの切り替え。

## 操作

| 操作 | キー／マウス |
| --- | --- |
| 前進／後退 | W / S |
| 左右旋回 | A / D |
| 上向き／下向き | ↑ / ↓ |
| 垂直上昇／下降 | Space / C |
| 加速 | Shiftを押しながら移動 |
| 光を照射 | 左ボタンを長押し、または F |
| 照準の方向を変更 | 左または右ボタンを押してドラッグ |
| ガイド・神／悪魔切り替え | H または右上の ? |
| 一時停止 | Esc または右上の Ⅱ |
| 世界を初期状態に戻す | R または右上の ↻ |

タッチ端末には前進・旋回・上下移動・照射ボタンを表示します。現段階の操作調整と性能評価はPCを中心にしています。

## 技術と計画

詳しい選定理由・実装順序・完了条件・拡張設計は [docs/PLAN.md](docs/PLAN.md) にあります。

- 現在の試作：Three.js / JavaScript / WebGL 2。UIはHTML/CSS。
- `dist/js/model.js`：描画に依存しない、地形・ボクセル・材質・火災・住民・反撃拠点の状態。
- `dist/js/game.js`：3D描画、入力、飛行、照射、弾道、カメラ、音、HUD。
- `tests/model.test.mjs`：破壊・延焼・崩落・避難・反撃の回帰確認。
- `tests/browser.mjs`：この作業環境の既存Playwright/Chromiumによる表示・操作確認。ブラウザのパスはこの環境向けです。

Node.jsがあれば計算部分を確認できます。

```bash
node --test tests/model.test.mjs
```

## 試作の範囲

地下空洞・横穴を作る完全な3D地形ボクセル、剛体同士が積み上がる瓦礫、地上への着陸、飛行艇、保存、ゲームパッドは未実装です。地形は柱の高さを削る方式、崩落片は演出用の軽い粒子、住民は簡易な回避・避難行動です。樹木と遠景の島は装飾です。照射の当たり判定は短い間隔のレイサンプリングによる近似です。

設定ガイドは開くとシミュレーションを停止します。ウィンドウがフォーカスを失うと、手動プレイは一時停止します。Google Fontsは表示上の補助として読み込み、取得できなくてもゲーム本体は同梱ファイルで動きます。
