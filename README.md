# AETHERFALL — 神域の残響

ローポリの王国を、人間サイズの神／悪魔で飛ぶ破壊サンドボックスの操作試作です。初代ヴァルキリープロファイルの俯瞰ワールドマップから「空を飛び、地上の営みを見下ろす」感覚に着想を得ています。地形・建物・キャラクター・UIは今回のために手続き生成した独自のものです。

## 現在の版：自由飛行と3種類の攻撃 α0.7.4

タイトルまたは飛行ガイドの「塔の崩落を試す」から、同じ切り欠きで塔を折れます。張り出し屋根と広場を切り替えて「塔を折る」を押すと、接触点の最大落下距離と壊れた個数が表示されます。瓦は2m、木材は6m、石材は12mから、着地した部分とその周囲が割れます。

主人公は96pxの背面ドット絵です。滞空・前進・左右旋回・突進・反動の宙返り・光線の構えと照射を操作に合わせて再生します。三筋の光翼は肩甲骨の左右から生え、付け根から先端へ順に羽ばたきます。髪・腕・胴体に光翼が重なる部分は、通常時も突進時も翼を手前に描画します。前進で翼を流し、旋回で左右の振幅を変え、宙返りでは小さく畳みます。突進の拡張翼は別のエフェクトで、光線の溜めで両翼は画面左に流れ、照射中は右手を空けたまま上下に分かれて揺れます。

飛行コースでは、光線・体当たり・光粒を使用できます。敵の反撃は停止中です。大通りを屋根の高さまで降下して南の石門をくぐり、前進を押しながら左上入力で青緑の塔を回る練習コースです。塔の向こう側で尖塔を越えると完走。↻ または R で入口に戻れます。低く飛ぶと進路上の住民が脇に避けます。光線、体当たりの本体・翼、光粒の爆発に触れた住民は、黒いシルエットから灰のドットになって消えます。

- **右の前進ボタン**：押している間に前進し、離すと滑らかに減速・停止。
- **左のバーチャルパッド上下**：前進と独立した垂直上昇・下降。その場でも使える。
- **左パッド左右**：左旋回・右旋回。横への平行移動ではない。
- **斜め入力**：上昇と左旋回などを1本の指で同時に操作。前進ボタンとの2点同時タッチに対応。
- **キーボード**：Spaceで前進、W/Sで上昇・下降、A/Dで左右旋回。矢印キーでも昇降・旋回できます。
- 1で光線を構え、0.7秒後に照射。パッドまたはWASDで照準を動かし、再入力か前進で解除。
- 2で体当たり。光の翼が左右に広がり、かすめたブロックにも一度ずつダメージを与えます。残り耐久値に応じて傷が3段階で広がり、木には木目沿いの裂けとささくれ、石には枝分かれするヒビ、瓦には角や縁の欠けが現れます。宙返りは本体の進路で判定します。木や瓦、壊しきった石を突き破ります。次の石が一撃に耐えるか地面に当たると発動位置へ宙返りし、与えたダメージと開いた穴は残ります。
- 3で光粒を切り替え。水平移動距離に応じて真下へ投下し、高いほど間隔が開きます。
- 上下移動は独立したまま、キャラクターは実際の移動速度に合わせて姿勢を変える。前進で前傾、加速でさらに前傾し、上昇・下降で上下を向き、左右旋回で翼ごとバンクする。
- キャラクターの傾きは滑らかに追従し、停止すると直立に戻る。方位と姿勢を別の階層で管理し、どの方角でも同じ方向へ傾く。カメラと移動計算は見た目の傾きから独立。
- プレイ中と飛行デモのカメラは中央の真後ろから追従。旋回中もキャラクターの位置を画面の左右中央に保ち、バンクが左右同じ配置で見えるようにする。
- `/?demo=1` は城門コースを一周する自動飛行デモ。元の破壊処理は計算モジュールに保持。

`tests/browser.mjs` はパッドの斜め入力、前進とのマルチタッチ、垂直移動の独立性、左右のバンク、昇降・速度による傾き、停止時の姿勢復帰、入力解除、3種類の攻撃を確認します。以下の破壊サンドボックスの説明は初期版の機能・設計の記録です。

## 起動

Python 3があれば、プロジェクトのフォルダで以下を実行してください。

```bash
python3 -m http.server 4173 --directory dist
```

ブラウザで <http://localhost:4173> を開きます。ゲーム本体のnpmインストールやビルドは不要です。Three.js 0.187.0を同梱しています。WebGL 2対応ブラウザで遊べます。最初の画面の「コースの見本を見る」、または `/?demo=1` で自動飛行を観察できます。

## 今回できること

- 約400m四方の島を後方カメラで自由飛行。通常32m/s、加速時97m/sを目標速度とする慣性移動。
- 人間サイズの翼あるキャラクター。光の神／闇の悪魔をガイド画面で切り替え。
- 神の光の連続照射で、城・民家・外壁の約5,500ボクセルを破壊。木・石・屋根材で耐久力と燃焼特性が異なる。
- 地面の4mブロック列を削り、段状のクレーターを残す。草地が削れると土・岩の断面が現れる。
- 熱の蓄積、着火、近隣への延焼、燃え尽き。石は燃えない。
- 地面に接続しなくなった建物の部分を検出し、崩落させる。
- 56人のドット絵住民が地上を移動し、照射地点・低空のプレイヤーから逃げる。
- 3基の投石機が放物線の岩を、3人の魔導師が追尾弾を撃つ。足場を破壊すると停止。
- 反撃の命中、神威の回復、尽きたときの天空への復帰。ミニマップ、一時停止、世界再生成、サウンドの切り替え。

## 操作

| 操作 | キー／マウス |
| --- | --- |
| 前進 | Space |
| 左右旋回 | A / D |
| 垂直上昇／下降 | W / S または ↑ / ↓ |
| 加速 | Shiftを押しながら移動 |
| 薙ぎ払いレーザー | 1で切り替え、WASDで照準。Spaceでも解除 |
| 体当たり | 2 |
| 光粒の自動投下 | 3で切り替え |
| ガイド・神／悪魔切り替え | H または右上の ? |
| 一時停止 | Esc または右上の Ⅱ |
| 世界を初期状態に戻す | R または右上の ↻ |

タッチ端末では左パッドに加え、前進・光線・体当たり・光粒の各ボタンを表示します。現段階の操作調整と性能評価はPCを中心にしています。

## 技術と計画

詳しい選定理由・実装順序・完了条件・拡張設計は [docs/PLAN.md](docs/PLAN.md) にあります。

- 現在の試作：Three.js / JavaScript / WebGL 2。UIはHTML/CSS。
- `dist/js/model.js`：描画に依存しない、地形・ボクセル・材質・火災・住民・反撃拠点の状態。
- `dist/js/game.js`：3D描画、入力、飛行、照射、弾道、カメラ、音、HUD。
- `tests/model.test.mjs`：破壊・延焼・崩落・避難・反撃の回帰確認。
- `tests/browser.mjs`：この作業環境の既存Playwright/Chromiumによる表示・操作確認。ブラウザのパスはこの環境向けです。

Node.jsがあれば計算部分を確認できます。

```bash
node --test tests/model.test.mjs
```

## 試作の範囲

地下空洞・横穴を作る完全な3D地形ボクセル、剛体同士が積み上がる瓦礫、地上への着陸、飛行艇、保存、ゲームパッドは未実装です。地形は柱の高さを削る方式、大きな崩落片は支点・重心と鉛直接触による簡易シミュレーション、小さな欠片と粉塵は短時間の粒子、住民は簡易な回避・避難行動です。樹木と遠景の島は装飾です。照射の当たり判定は短い間隔のレイサンプリングによる近似です。

設定ガイドは開くとシミュレーションを停止します。ウィンドウがフォーカスを失うと、手動プレイは一時停止します。Google Fontsは表示上の補助として読み込み、取得できなくてもゲーム本体は同梱ファイルで動きます。
